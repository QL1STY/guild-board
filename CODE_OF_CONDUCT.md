# Code of conduct

Be kind and be plain. Criticise code and ideas, not people. No harassment, no insults and no sharing of other people's private information, in issues, pull requests or anywhere else the project is discussed. Anyone who keeps doing so may be asked to leave the project's spaces.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), and its text is the standard to read it by. To report a problem with someone's behaviour, use GitHub's private reporting on this repository (see [`SECURITY.md`](SECURITY.md)).
